# 全面废除矩形框，左右分区与半透明叠加全量统一为三线正交锚定模型

> 针对初步试用中暴露出的“矩形框与三线双体系割裂、矩形框无法精准对齐头顶与双脚、播放页切换模式需补标定繁琐”的问题，我决定全面废除矩形框体系与多余的微调滑块，将左右分区与半透明叠加全量统一收敛为“两横一竖 / 两竖一横”三线正交锚定模型，以达成极简纯粹的用户心智模型与 100% 免重标定的无缝模式切换。

**历史注记（2026-11-25 核对）**
>
> 本篇第 2 条中的「对齐至左半区中心轴线 `x = halfWidth / 2`」与「上方留出 40%+ 的开阔天空」
> 已被 **AgDR-0013**、**AgDR-0014** 修订：左 / 右半区中轴现为半区宽度的 47.5% / 52.5%，
> 人物特征高度为半区高度的 65.5%，上方留白约 29.5%，脚底沉底 95%。
> 当前实现见 `src/core/geometry.ts:186-192`。本篇核心决定（废除矩形框、模式切换免二次标定）仍然有效。

## 考虑过的方案

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| 全量统一为三线正交锚定模型（废除矩形框） | 全系统只有一种几何对齐概念；左右分区与叠加模式共用同一组三线标定，模式切换 0 成本无缝衔接；中轴、头身比与脚底对齐精度极高，且完全保留全视野挥棒空间 | 废弃此前矩形框相关代码与类型契约 |
| 保留矩形框与三线双模式，并在播放页提供多个拖动条微调 | 满足特定场景的局部矩形放大 | 概念割裂，拖动条操作繁琐破坏自动化对齐，心智负担重，切换模式时体验割裂 |

## 决定

1. **彻底废除矩形框标定（`cropRect`）与播放页冗余微调拖动条**：
   - 图像标定步骤中不再提供矩形拉框交互，全量统一为**三线正交标定**（「两横一竖」或「两竖一横」二选一）；
   - 播放工作台右下角移除冗余的微调拖动条，保持界面极简清爽。
2. **左右分区的统一三线投影算法**：
   - 左半区：以视频 1 的三线特征尺寸 $D_1$（两横线间距或两竖线间距）为基准，缩放到半区基准高度 $H_{\text{target}}$，锚点中心平移对齐至左半区中心轴线（$x = halfWidth / 2$）；
   - 右半区：以视频 2 的三线特征尺寸 $D_2$，同样缩放到与视频 1 相同的半区基准高度 $H_{\text{target}}$，锚点中心平移对齐至右半区中心轴线（$x = halfWidth / 2$）；
   - 整幅原视频画面完整绘制，黑框与截断概念彻底消失，上方留出 40%+ 的开阔天空完整包容挥棒大光弧。
3. **模式切换免二次标定**：
   - 因为左右分区与半透明叠加共用同一套三线参数，用户在播放工作台随时自由切换模式，无需进行任何二次补标定。

## 代价

- 我们接受：删除 `cropRect` 类型与矩形手柄交互代码。
- 我们放弃：不再维护双重标定状态机。

## 什么情况下需要重新讨论

- 若未来增加四点透视梯形校正需求时重新评估，目前纯三线正交模型已完全满足 WOTA 艺练技诉求。
