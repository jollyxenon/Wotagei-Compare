# 双通道时间片段截取与左右分区视口人物放大

> 在 WOTA 艺技连长视频多曲导致全局 BPM 识别失真、对比台人物主体在手机端偏小且空间标定指示框偏侧杂乱的处境下，面对长视频无裁切对比盲区与小屏看不清动作发力细节的顾虑，我决定：
> 1. 将音频对拍升级为时间标定，在波形轴引入双端可拖动 `[` 与 `]` 手柄，拖动后基于截取区间单声道 PCM 重算局部 BPM，锚点时间戳绝对值保持不变；
> 2. 对比台统一时间轴升级为两通道各自截取后的有效重叠交集（Intersection Interval）；
> 3. 左右分区人物特征尺度提升至半区高度的 68%~70%，双脚基准线沉底至 94%~95%，头顶线约 26%~27%；
> 4. 三线标定指示框全部统一水平居中骑在标定线上，彻底消除垂直线指示框偏置；
> 以达成移动端小屏极清、技连核心招式毫秒级聚焦对比与指示规范统一的目标，并接受局部截取区间之外的内容在对比台完全不可见的代价。

**历史注记（2026-11-25 核对）**
>
> 本篇第 3 条「人物特征尺度 68%~70%、脚底 94%~95%、头顶线 26%~27%」已被 **AgDR-0014** 收敛为
> 半区高度 65.5%、脚底 95%、上方留白约 29.5%。
> 当前实现见 `src/core/geometry.ts:186-192`。本篇其余决定仍然有效。

## 考虑过的方案

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| **方案 A：保持全局音频分析与全视频交集，仅增加对比台时间轴手动缩放** | 无需在标定阶段增加交互与数据结构变更 | 多歌曲技连视频的 BPM 始终是全局错乱的，无法准确生成目标招式的节拍刻度；对比台需要频繁缩放寻找目标招式 |
| **方案 B（入选）：时间标定引入 `[` 与 `]` 局部截取，动态自相关重算局部 BPM，对比台基于截取交集** | 技连视频中每一技可独立框取纯净音频片段测出极准 BPM；对比台直达该招式，零干扰；配合 70% 比例沉底视口极大改善小屏体验 | 需在内存中暂存解码 PCM 数据供即时切片计算；两视频若截取招式长度不同，对比台仅呈现双方均覆盖的交集重合期 |
| **方案 C：对比台统一时间轴采用截取后的并集（Union）** | 允许某一路视频比另一路多放一段（单侧动作提前或延后结束） | 一旦进入单侧盲区，另一侧画面静止或黑屏，丧失同台对比意义；且导出视频包含单边静止废帧 |

## 决定

选 **方案 B**，因为：
1. WOTA 艺练习者录制的视频通常为一整套技连（例如包含前奏、雷蛇、烈火、村正等多首曲目），整段视频跨越多个不同 BPM 的音乐片段。若不能局部框定招式起止范围，自动 BPM 检测必然失效；
2. 基于内存暂存的单声道 `Float32Array`，在用户拖拽起止手柄时取切片重新运行能量自相关检测，耗时仅几毫秒，能提供即时精准反馈；
3. 用户明确确认：对比台统一时间轴应严格对比两通道截取后的有效重叠交集（Intersection），严禁单边黑屏或静止；
4. 手机端 60% 的人物比例与 85% 脚底位置在小屏设备上留有过多地面与背景黑边，参考实际测试标注图，将脚底沉底至 94%~95%、比例提升至约 68%~70%，既显著放大了身体与手臂动作，又保留了上方约 26%~27% 的空间完全包容挥棒大光弧。

## 代价

- 我们接受：用户在时间标定中一旦框定了 `[start, end]`，进入对比台后该通道在截取区间外的内容将被完全滤除，如需比对其他招式需重新调整起止手柄；
- 我们接受：在拖动起止手柄导致原锚点落在区间外部时，维持锚点原始数值不变（不强行 Clamp），用户可自由在波形上点击重新指定锚点；（**注：该代价已被 [AgDR-0014](AgDR-0014-时间截取锚点约束与分区分屏视角微调.md) 废除与取代，现已全量改为强制 Clamp 策略**）
- 我们放弃：空间标定中垂直中轴线与左右脚线指示框偏置在线侧的旧布局，全部改为居中置于线上。

## 什么情况下需要重新讨论

- 如果用户要求在对比台中支持多段招式随时切换（例如招式列表管理）而不仅是单段起止截取时，重开此记录。
